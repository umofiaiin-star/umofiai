# Umofi AI - Website Project

A complete, editable HTML/CSS/JS website for Umofi AI - AI Services in Hyderabad.

## Project Structure

```
umofi-ai-project/
├── index.html          # Main HTML file
├── css/
│   └── style.css       # All styles (42KB)
├── js/
│   └── script.js       # All JavaScript (15KB)
├── images/
│   └── image_0.jpg     # Logo image
├── icons/
│   ├── icon_0.svg      # WhatsApp icon
│   ├── icon_1.svg      # Back to top icon
│   ├── icon_2.svg      # Social icon
│   ├── icon_3.svg      # Social icon
│   └── icon_4.svg      # WhatsApp icon (duplicate)
└── README.md           # This file
```

## Features

- Responsive design (320px to 1440px+)
- Custom cursor with hover effects
- Animated hero section with glitch text
- Service cards with hover effects
- Testimonials, FAQ accordion, Contact form
- WhatsApp floating button
- Back to top button
- Google Fonts: Playfair Display + Outfit
- SEO optimized with Schema.org JSON-LD

## How to Edit

1. Open `index.html` to edit content and structure
2. Open `css/style.css` to edit colors, fonts, spacing, animations
3. Open `js/script.js` to edit interactions and behavior
4. Replace `images/image_0.jpg` with your own logo

## Key CSS Variables

Edit these in `css/style.css` to change the theme:

```css
:root {
  --bg: #03040A;        /* Background */
  --text: #EEEEFF;      /* Text color */
  --p: #7B5CFF;         /* Primary purple */
  --p2: #5BA4FF;        /* Secondary blue */
  --p3: #B49FFF;        /* Accent */
}
```

## Fonts
